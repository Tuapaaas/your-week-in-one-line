One line summing up the entrant's week — eighty-five bounty entries, zero wins, and a spreadsheet that still believes next week is the one.

## Run it

```sh
node main.ts
```

This writes the line to `entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program self-checks the 1–100 character, single-line gate before writing.
